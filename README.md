# 🌟 Контролер «розумного освітлення» на базі STM32

Цей репозиторій містить курсовий проєкт з розробки мікропроцесорної системи керування динамічним RGB-освітленням. Проєкт поєднує низькорівневе програмування мікроконтролера (Bare-Metal) із сучасним вебуправлінням через локальний Python-сервер.

## 📌 Особливості проєкту

* **Bare-Metal розробка:** Ініціалізація та керування периферією (RCC, GPIO, TIM, USART) реалізовані через прямий доступ до регістрів мікроконтролера без використання високорівневих бібліотек (HAL/Standard Peripheral Library).
* **Неблокуюча архітектура (FSM):** Логіка роботи побудована на базі кінцевого автомата станів, що дозволяє системі генерувати плавні ШІМ-анімації та миттєво реагувати на нові UART-команди без використання функцій затримки (`delay`).
* **Апаратний ШІМ (PWM):** Плавне змішування кольорів та регулювання яскравості забезпечується апаратними таймерами (TIM2, TIM3).
* **Клієнт-серверна архітектура:** Замість класичного текстового термінала використовується Flask-шлюз та інтерактивний веб-інтерфейс.

## 🗂 Структура репозиторію

* 📂 **Firmware/** — вихідний код мікроконтролера (`main.c`), скрипт компонувальника (`.ld`) та готові бінарні файли прошивки (`.bin`, `.elf`).
* 📂 **Server/** — файли серверної частини та веб-інтерфейсу.
  * 📄 `server.py` — локальний сервер-шлюз (Python/Flask) для роботи з UART.
  * 📂 `templates/` — директорія з HTML/JS/CSS файлами веб-інтерфейсу (`index.html`).

## 🛠 Апаратне забезпечення

* Відлагоджувальна плата **STM32 Nucleo-F446RE** (мікроконтролер STM32F446RET6).
* Зовнішня RGB-світлодіодна стрічка.
* Підключення ШІМ-каналів:
  * **Red (Червоний):** PB4 (TIM3_CH1)
  * **Green (Зелений):** PB10 (TIM2_CH3)
  * **Blue (Синій):** PB0 (TIM3_CH3)

## 🚀 Режими роботи (Ефекти)

Система підтримує такі режими індикації:
1. **Static White (або будь-який колір):** Статичне світіння вибраним на палітрі кольором з можливістю зміни яскравості.
2. **Rainbow:** Плавний циклічний перелив усіма кольорами веселки.
3. **Breathing:** Плавне пульсування інтенсивності світла.
4. **Cosmos:** Глибоке синьо-пурпурове «дихання».
5. **Lightning:** Ефект грози із різкими білими спалахами.
6. **SOS:** Сигнальний режим у червоному спектрі (азбука Морзе).

## 💻 Як запустити проєкт

### 1. Прошивання мікроконтролера
Завантажте файл `blink.bin` (з папки Firmware) у мікроконтролер за допомогою утиліти **STM32CubeProgrammer** або скомпілюйте `main.c` у середовищі STM32CubeIDE та прошийте плату через вбудований ST-LINK.

### 2. Підключення
Підключіть плату Nucleo до комп'ютера через USB-кабель. Переконайтеся, що система розпізнала віртуальний COM-порт (наприклад, `COM3` для Windows або `/dev/ttyACM0` для Linux).

### 3. Запуск сервера
Встановіть необхідні залежності для Python (якщо вони ще не встановлені):
```bash
pip install flask pyserial
```

Відкрийте файл `Server/server.py`, перевірте, чи збігається назва порту у змінній `SERIAL_PORT` з вашим системним портом (наприклад, `COM3`), і запустіть сервер:
```bash
python server.py
```

### 4. Керування
Відкрийте веббраузер та перейдіть за адресою:
```text
http://localhost:5000
```
Використовуйте зручний графічний інтерфейс для керування освітленням у реальному часі!
